**What students do**

Set the test readout, run a baseline, change exactly one variable, run the same track again, read the two results side by side, and record what the change actually did.

**What is pre-built for them**

The test track, timing, the re-run button, and reaction capture. The comparison dialog fires by itself at the end of the second run.

**STEM skills applied**

Controlled comparison, isolating a single variable, reading instrumentation, and iterating on a result.

**Career lens**

Test engineer: Jordan.

**Size**

6 coded steps, plus an opening card and a closing card.

**What students should leave thinking**

*"The comparison is the answer. One run on its own tells me almost nothing."*
